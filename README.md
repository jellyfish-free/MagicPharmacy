# アステル教授の植物学実習帳

GitHub Pages向けの静的ゲームです。次のファイルをすべて同じフォルダ（リポジトリのルート）に置いてください。

- `index.html` — ページ構造
- `style.css` — デザイン
- `game.js` — 図鑑60種、授業・探索、所持品、履歴、セーブ機能

## GitHub Pagesで公開する手順
1. GitHubでリポジトリを作成します。
2. 3ファイルをリポジトリの直下にアップロードします。
3. Settings → Pages を開きます。
4. Build and deployment で `Deploy from a branch` を選び、Branchを `main`、フォルダを `/(root)` にして保存します。
5. 公開URLが表示されたらアクセスします。

## セーブデータ
進行状況はブラウザの localStorage に保存されます。別端末に移す場合は研究記録からセーブデータを書き出し、移行先で読み込んでください。ブラウザデータを消すとセーブも消える場合があります。

## 追加した発見イベント
「温室実習」→「根元の土を調べる」を選ぶと、光る花の根元に眠る魔力を調べるイベントが発生し、No. 038「魔力を帯びた土壌」を入手します。教授の台詞と研究メモ、図鑑説明も反映済みです。

このゲームはブラウザ内保存の試作版で、サーバー同期機能はありません。


## 授業・調査方法
調査方法は授業を受けている生徒自身が行う内容に統一しました。白狐に調査を任せる選択肢はありません。授業は1日3回までで、日付が変わると回数がリセットされます。
